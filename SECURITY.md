# Security policy

GROM Exchange (https://grom.exchange) is a non-custodial interface: users connect their own wallets and sign every transaction themselves. GROM does not hold user funds, seed phrases or private keys.

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue.

- Email: **support.grom@gmail.com** with the subject `SECURITY`
- Or a private message to [@GromExchange](https://x.com/GromExchange) on X asking for a secure contact

Include:

1. The affected page or endpoint and the network involved
2. Steps to reproduce, and what you expected to happen
3. The impact you believe the issue has

We acknowledge reports as soon as we can and keep you updated while we investigate. Please give us reasonable time to fix an issue before any public disclosure.

## In scope

- The web application at `grom.exchange` and its public API
- Anything that could cause a user to sign a transaction different from the one shown in the interface

## Out of scope

- Third-party protocols, bridges, aggregators and wallets that GROM routes through — please report those to their own teams
- Social-engineering, phishing of individual users and denial-of-service attacks

## Stay safe

GROM will **never** ask for your seed phrase, private key or wallet password, and never asks you to send funds to "verify" a wallet. Always check that you are on `grom.exchange` before connecting a wallet.
